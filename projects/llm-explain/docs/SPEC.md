# SPEC：softmax 注意力的精确结构

> **本工程形式化的对象是一个 softmax 注意力头作用在自由给定的分数向量与值向量上，
> 外加一个残差求和。** 定理里**没有权重矩阵**：`z`（分数）与 `v`（值）是自由变量，
> 不由任何投影产生。

## 0. 这个工程有什么，没有什么

**有**（全部已形式化）：

- 任意分数向量上的 softmax：`p_i = e^{z_i} / Σ_j e^{z_j}`；
- 任意值向量上的加权平均：`attn p v d = Σ_i p_i · v i d`；
- 残差求和：`block z v x d = x d + attn (softmax z) v d`；
- 行/列意义下的线性注意力层 `X ↦ P · X · W`（`P`、`W` 为**给定**矩阵）。

**没有**（这些**不在**形式化里，任何"DeepSeek 架构"的说法都超出了范围）：

| 真实 transformer 层有 | 本工程 |
|---|---|
| Q/K/V 投影、权重矩阵 | ❌ 完全没有；`z`、`v` 是自由变量 |
| 多头注意力、输出投影 | ❌ 单头 |
| RoPE / 任何位置编码 | ❌ |
| RMSNorm 进入残差流 | ❌ `rms` 只有一条独立齐性引理，`block` 不含归一化 |
| MLP（含 gated/SwiGLU） | ❌ |
| 因果掩码 | ❌ |

**因此**：本工程证的是**关于 softmax 本身与加权平均的结构事实**，不是关于任何一个
训练好的模型的陈述，也不是关于 DeepSeek 4.1 的陈述。点名具体模型不增加任何数学内容。

## 1. 为什么不直接用上一项目的理论

`~/cnn-explain` 的核心是分段线性：激活胞腔上精确等于仿射映射。softmax 有 `exp`，
是实解析的，没有有限胞腔分解——所以精确仿射解释不存在。

本工程改走两步：先证**精确的结构事实**（概率、凸组合、只依赖分差、单调），
再给**带误差的界**（gap 控制 top-1 权重；注意力输出与单个值之差）。

## 2. 对象定义台账

| 符号 | 定义 | Lean |
|---|---|---|
| `softmax z i` | `exp (z i) / ∑ j, exp (z j)` | `LlmExplain.softmax` |
| `attn p v d` | `∑ i, p i * v i d` | `LlmExplain.attn` |
| `weight2 f a b` | `f a / (f a + f b)`（**两位置**权重） | `LlmExplain.weight2` |
| `rms x` | `sqrt ((∑ d, x d ^ 2) / \|D\|)` | `LlmExplain.rms` |
| `block z v x d` | `x d + attn (softmax z) v d` | `LlmExplain.block` |
| `linLayer P W X` | `P * X * W`（线性注意力层） | `LlmExplain.linLayer` |

## 3. 假设

| ID | 陈述 | 说明 |
|---|---|---|
| (H1) | `I`、`D` 有限非空 | softmax 分母需要至少一项 |
| (H2) | 「gap」类结论要求 `δ > 0` 且最大分严格高于其余 | 平局时界退化 |
| (H3) | 两位置刻画要求 `f > 0` | 无正性时乘性 Cauchy 方程还有 `g ≡ 0` 等解 |

## 4. 结论与状态（以 `docs/CLAIMS.md` 为准）

**精确的**：C1–C6（softmax 是概率分布、凸组合、只依赖分差、单调）、
C9（`rms` 一次齐性）、C10–C11（残差块范围与代理差）、C14–C15（值路径 Lipschitz）、
C20–C21（线性层复合、残差交叉项）。

**带 gap 的定量结果**：C7（top-1 权重下界）。**C8 无条件成立**——它对任意 `i₀`
给出 `(1 − p i₀) · 2M`，不需要 gap；gap 只在 C7 里把 `1 − p` 变小。
两者合起来才有"gap 小 ⇒ 逼近"的意思，但这条**合并陈述本身没有单列**。

**两位置刻画**：C16（平移不变 ⇒ 乘性 Cauchy 方程）、C17（指数族满足）。
**C19 是缺口**：乘性 Cauchy 方程的连续解分类，未形式化。

**可逆性（论文主定理）**：C23（仿射无关 ⇒ 输出确定权重）、C28（仿射相关 ⇒ 存在第二个
概率向量给出同一输出）——两条合起来是**双向**的"当且仅当"。C24（softmax 相同 ⇔ 分数差常数）。
C25（仿射无关 ⇒ `|I| ≤ |D| + 1`）、C26（模糊度 ≥ `|I| − (|D| + 1)` 维）、
C27（核方向不改变输出与权重和）。

**开放**：C18（深度层级猜想），**不作为论文主张**。

## 5. 可伪性

1. **常向量**：`z = 0` ⇒ `softmax 0 i = 1/|I|`（C3 的直接检验）。
2. **平移不变**：`z` 与 `z + c·1` 给出同一 softmax（C5）。
3. **极端情形**：`|I| = 1` 时 C7 的界应为 1，与 `softmax = 1` 相符。
4. **反例方向**：把 softmax 换成未归一化的 `exp`，C1–C3 必须失效。
5. **常数紧性**：C8 的 `2M`，取 `I = Fin 2`、`z = 0`、`v = (2, −2)`、`M = 2` 时取等；
   换成 `M` 则失效（审计已用 Lean 验证）。

## 6. 范围外（明确不做）

- **权重、投影、多头、RoPE、RMSNorm 进残差流、MLP、因果掩码**。见 §0 的表。
- **具体模型、具体 token 的解释**。不是数学命题。
- **训练动力学、涌现能力**。不可形式化。
- **分段线性的精确解释**。softmax 破坏它；本工程只给界的组合。
