### 被驳倒的怀疑（值得记录，因为它们是最像问题的地方）

- **`walk` 的复合顺序是否左右反了**：审计员用两层仿射网络 `f1=(2,1)`、`f2=(3,1)` 数值核对，
  `linOf` 给出 `6y₀+4`（正确），反序会得 3。→ REFUTED，两次偏置都进了常数项。
- **池化分支的 `Classical.choose` 推理是否成立**：`Pat.pool.inj` 给出 `choice y = choice x`，
  再用 `apply_eq_select` 在 `y` 处展开——逐步复核成立。→ REFUTED。
- **`regionOf` 是否退化成单点**：构造了 `net` 使区域落在超平面 `{y₀=1}` 上且含无穷多点；
  "只锁一维需要两个坐标、必留自由维"，没能构造出单点区域。→ REFUTED。
- **`Fin n` 的加法回绕是否让"卷积"变成别的东西**：`Fin 3` 中 `2+2=1`，`K=δ₁`、`x=(1,2,3)`
  时 `convOp K x = (2,3,1)`，与手算一致。→ REFUTED（回绕是建模选择，不是 bug）。
- **`z=0` 是否被静默归入开分支**：`decide (0 < x i)` 在 0 处为 false，归"关"，
  且 `boundary_agrees` 证两分支相等。→ REFUTED。
- **是否存在反例**：SPEC §4 的五条可伪性测试全部通过（恒等网络、单 ReLU / x=±1、
  边界、两层偏置）。→ 未找到反例。

## 3. CONFIRMED：一处过度声称（已修）

`docs/CLAIMS.md` 原文说：本工程区别于"全连接网络分段线性"文献之处是
**"解释按感受野分解"**。

**代码里没有这条定理。** `cnn_explanation` 只是把 `[conv, relu, pool]` 塞进 C5，
`linOf` 仍是整条网络的**稠密**仿射映射，没有证明任何稀疏性、Toeplitz 或感受野结构。

**处理**：删去该声称，改写为一条明确记录，并把"把 M 的卷积结构写成定理"列为未做工作。
这正是 `statement` 门看不见的那一类错误——它比的是类型，不比散文。

## 5. 价值判断（第三路审计，必须原样记下）

审计员的结论是：**作为论文的主定理——不够。**

理由：

1. 它本质上是"ReLU 网络在激活区域上是仿射"这一**标准事实**（CPWL / linear regions 文献）
   在 Lean 里的忠实编码；证明是定义展开的归纳，无实质新引理。
2. "解释" `M` 的大小是 `|G|²`，与稠密层同阶——**没有压缩、没有局部化、没有可读性**。
3. 覆盖的是**风格化网络**：等宽、循环卷积、不下采样、无偏置、只有 ReLU 与 max 池化。
   真实 CNN 的下采样和变宽分类头都不在模型里。
4. `regionOf` 的定义把"解释"放宽到"分段线性闭式"，命题几乎由构造成立。

**后续**：建议里的第一条（局部有效半径）**已实现**——台账 C14–C17：
ReLU 符号稳定、池化选择稳定、递归半径 `Bounds ⇒ Stable`、以及球上的完备解释
`local_region`。第三条（**感受野结构**）也已实现——台账 C18：`rowSupport` 递归给出
每个输出坐标依赖的输入坐标集合，并证 `M i j ≠ 0 ⇒ j ∈ rowSupport i`。
**唯一性**也已补上（台账 C19/C20）：`Bounds` 成立且 R>0 时，任何在球上与网络相等的
仿射映射都等于 `linOf net x`。这一条把"存在一个解释"升级为"解释被唯一决定"，
是审计所说"区域几何"那一条的实质用途——C17 已给出球在区域内部，故唯一性成立。
仍缺的是区域的**显式几何描述**（半空间之交、满维证明）与范围扩张。

**它建议补什么才有分量**：

- **局部有效半径 / 鲁棒证书**（最有价值）：设 x 处前激活 margin ≥ ε、池化窗口 gap ≥ δ，
  证 `B(x, r) ⊆ region`，`r` 为各层 Lipschitz 常数与 `ε, δ` 的显式函数。
  这把"精确线性化"变成"可用的局部证书"，证明非平凡。
- **区域几何**：把 `regionOf` 写成半空间之交，证满维凸多面体，并给不同区域数的上界。
- **感受野结构定理**：证胞腔上的 `M` 保持卷积稀疏 / Toeplitz 结构（即 C3 那条空声称的补救）。
- **范围扩张**：stride / 下采样、零填充卷积、变宽与分类头。

## 6. 仍然缺的

1. 没有证明区域满维或有非空内部（P4）。
2. 没有证明"按感受野分解"（§3）。
3. `layer` 的卷积偏置为零；真实 CNN 有偏置（加偏置不改变结论，只是没写）。
4. 独立审计的审计员与本工程使用同一模型家族——**这是审查者多样性上的残余局限**，
   不是"已由人类同行复核"。
