# SPEC：CNN 的完备解释（精确线性化）

> 目标：对**每一个**输入，存在一个**精确**的、可机械验证的解释。
> 不是"小到人能读"，是"没有遗漏、没有近似"。
> 本文件是 P0 的产物；结论一旦锁定，内环的证明不得改动它。

## 0. 先把"可解释"定义死

「完全可解释化」不是数学命题。本工程采用的定义是：

> **解释** = 一个有限的分段线性区域 + 一个仿射映射，使得网络在该区域上
> **恒等于**该仿射映射。
>
> **完备** = 对每一个输入都存在这样的解释，且**精确**（不是近似、不是下界）。

「紧凑」不在定义里。区域可以极小，仿射映射可以很大。这是刻意的：紧凑性有已知的
指数下界，要求紧凑就等于要求一个假命题。

## 1. 对象定义台账

| 符号 | 定义 | 定义域 | Lean |
|---|---|---|---|
| `Vec n` | `Fin n → ℝ` | `n : ℕ` | 待建 |
| `Mat n` | `Matrix (Fin n) (Fin n) ℝ` | 同上 | Mathlib `Matrix` |
| `Affine n` | `Mat n × Vec n`，作用于 `x ↦ A x + b` | 同上 | 待建 |
| `Layer n` | `affine (A, b)` 或 `relu` | 同上 | 待建 |
| `Net n` | `List (Layer n)` | 同上 | 待建 |
| `eval` | 逐层求值 | `Net n → Vec n → Vec n` | 待建 |
| `relu` | `x ↦ max x 0` | `ℝ → ℝ`（逐点） | Mathlib `max` |
| `sign z` | `z > 0`（开）与 `z ≤ 0`（关） | — | 待建 |
| `Pattern n` | 每层每个坐标的 `sign` 取值 | `Net n → Type` | 待建 |
| `linOf` | 给定 `Pattern` 后，把每层 ReLU 换成恒等或零，复合得到的仿射映射 | — | 待建 |
| `region` | `{y | 每一层的每个前激活值的符号都与 σ 一致}` | `Set (Vec n)` | 待建 |

**符号约定（关键）**：ReLU 关的分支用 `z ≤ 0`，开的分支用 `z > 0`。
于是 `z = 0` 归到"关"，而 `max 0 0 = 0` 与关分支的线性化 `0` 一致——
**边界上两分支相等**，所以结论在整个闭胞腔上成立，不需要"相对内部"。

## 2. 假设

| ID | 陈述 | 能否弱化 |
|---|---|---|
| (H1) | 有限维，且各层等宽：所有中间量都在 `Fin n → ℝ` | 不能弱化到变宽而不重写归纳；见 §5 |
| (H2) | 每层是仿射或 ReLU 之一 | 这是**定义**，不是假设 |
| (H3) | 层数有限 | 不能去：无限层不再分段线性 |
| (H4) | 标量域是 `ℝ`（有序域，`max` 良定义） | 可换任意线性序域，本工程不做 |

**注意 (H2) 的地位**：卷积与池化**不在**第一阶段的对象里。它们是"结构化仿射/选择"，
在第二阶段作为 `Layer` 的特例引入（见 §5）。这样第一阶段只依赖 Mathlib 的矩阵与
有限和，不依赖任何 CNN 语义。

## 3. 结论（量词写全）

设 `eval : Net n → Vec n → Vec n`，`linOf : Pattern → Affine n`，`region : Pattern → Set (Vec n)`。

$$\forall\, \text{net} : \text{Net } n,\ \forall\, x : \text{Vec } n,\ 
\exists\, \sigma : \text{Pattern}(\text{net}),\ 
x \in \text{region}(\sigma)\ \wedge\ 
\forall\, y \in \text{region}(\sigma),\ \text{eval}(\text{net}, y) = \text{linOf}(\sigma)(y).$$

**主定理（台账 C5）**：上式。

**推论（台账 C6，完备性）**：对每个 `x`，`eval net x = linOf (σ x) x`——
即**预测被激活模式唯一决定**，且这个决定关系是精确的仿射式。

注意结论里 `∃σ` 在 `∀x` 之后：**模式依赖输入**，不是全局的。

## 4. 可伪性（P0 门禁：三条以上）

1. **恒等网络**：`net = [affine (I, 0)]`。则应只有一个模式，`linOf = I`，
   结论退化为 `eval y = y`。若证不出这条，定义就错了。
2. **一维两段**：`net = [affine (1,0); relu]`。取 `x = -1` 与 `x = 1`，
   应属于两个不同模式，且 `linOf` 分别是 `0` 与恒等。手算可逐字核对。
3. **边界**：`x = 0`。必须落在"关"分支，且 `eval 0 = 0 = linOf_off 0`。
   如果把关分支写成 `z < 0`，这条会失败——这正是符号约定的检验。
4. **反例方向（必须失败）**：把 `relu` 换成 `sigmoid`。此时函数不是分段线性，
   定理必须不成立。若形式化后仍能"证"出来，说明定义里偷偷用了 ReLU 的性质。
5. **复合的常数项**：两层 ReLU 的 `linOf` 常数项必须包含中间层偏置的贡献；
   漏掉时一维手算立刻暴露。

## 5. 范围外（明确不做）

- **卷积与池化的具体结构**：**已完成**（台账 C8/C9/C10）。卷积写成循环矩阵、池化写成
  选择矩阵，`Layer` 增加池化构造子，CNN 作为 C5 的实例。
  **二维**（`G := Fin h × Fin w`）同样已完成（台账 C11/C12）：索引类型是任意的有限加法交换半群，
  二维不是第二套理论。**零填充**的边界效应已证（C13：等变性在边界失效，附显式反例）；
  把零填充卷积接成一个 `Layer`（它是有限维线性映射）只需要索引簿记，未做。
- **变宽网络**（各层维度不同）。需要依赖类型的层列表，形式化成本高，第一版不做。
- **紧凑性 / 可读性**。区间的个数随深度指数增长，这是已知下界，本工程不声称能压缩。
- **近似解释 / 显著性图 / Grad-CAM**。它们的正确性标准是人，不是 kernel。
- **"任意 CNN 等价于小规则表"**。这一般情况下为假；若要做，那是另一个（不可能性）项目。
- **感受野结构 / `M` 的稀疏性**。未证。`linOf` 是整条网络的稠密仿射映射；
  "解释按感受野分解"曾经写在台账里，审计指出代码中没有对应定理，已删除（见 `docs/AUDIT.md` §3）。
- **区域几何**。`regionOf` 的定义是"模式相同的点的集合"，没有证明它有非空内部或满维；
  它可能落在低维集合上（审计 P4）。定理在退化区域上照样成立，但"解释一个区域"
  在陈述里是未兑现的承诺。
- **真实 CNN 的若干结构**。本工程覆盖的是**风格化**网络：等宽、循环（或零填充）索引、
  不下采样、卷积偏置为零、激活只有 ReLU 与 max 池化。
  下采样 / stride、变宽与分类头、非线性激活（sigmoid 等）都不在模型里——
  对这些网络，本定理**真空成立**，不构成陈述。

## 5.1 术语

`convOp k x i = ∑ m, k m * x (i + m)` 在深度学习的用语里是**互相关**（cross-correlation），
不是数学意义上的卷积；因为 `k` 遍历整个向量，它与"翻转核的卷积"等价。
论文中必须写 cross-correlation，否则会被认为表述不准。
