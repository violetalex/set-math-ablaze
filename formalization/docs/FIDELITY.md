## 2. CONFIRMED 的条目

### C1（保真审计员，major）：轴上 Φ 的定义不同

**具体错误。** 论文 (eq:Phi) 把 `Φ` 定义为光滑提升 `g(|y|²,y₅,t)`，因此
`Φ(0,ζ,t)=g(0,ζ,t)=lim_{ρ→0}Γ/ρ²`，一般非零。Lean 的 `Phi Γ ρ ζ t = Γ/ρ²` 在 ρ=0 处
走 Mathlib 的 `x/0=0`，得到 `Phi Γ 0 ζ t = 0`。反例：`Γ=ρ²e^{-ρ²}`（满足轴正则 `Γ=O(ρ²)`），
论文 `Φ(0)=1`，Lean `Phi(0)=0`。因此 A34 在 ρ=0 只断言 `0 ≤ C₁/(2(1+√-t))`，
**没有**证明论文的 `|g(0,ζ,t)| ≤ C₁/(2(1+√-t))`。`omegaZeta` 在 ρ=0 同理（Lean 0，论文 `2g(0)`），
但它的唯一使用点已限制 `ρ≠0`，不影响证明。

**影响。** A35 在 ρ>0 上与论文逐字相同；论文的 `Φ` 连续，故 `ρ≥0` 上的 sup 等于 `ρ>0` 上的 sup，
A35 的 sup 内容不受影响。但作为**陈述**，A34/A35 在轴上都比论文弱：Lean 在 ρ=0 的断言是平凡的。
保真审计员按"不同命题哪怕更弱"的规则记为 major；陈述强度审计员对同一事实的严重性判断不同，
见 §3.2，原文照录，不调和。

**修法（择一）。**
1. 把 `Phi` 在 ρ=0 处定义为极限：新增假设
   `Tendsto (fun ρ => Γ ρ ζ t / ρ^2) (𝓝[>] 0) (𝓝 (Φ₀ ζ t))`，结论对 `Φ₀` 在 ρ=0 也断言；
   轴上界由 ρ>0 的一致界 + 连续性取极限得到。这是最贴近论文的写法。
2. 或把 `Phi` 定义为 `if ρ=0 then Φ₀ ζ t else Γ ρ ζ t / ρ²`，其中 `Φ₀` 是论文的 `g(0,ζ,t)`，
   并加假设 `∀ρ>0, Φ₀ ζ t = lim ...`；同样需要极限存在性。
3. 或（最省事的诚实写法）把 A34/A35 的结论限制到 `ρ>0`，并在台账里明确"轴上值未形式化"。
   当前实际状态等价于这一条，但陈述里仍写着 `ρ≥0`，容易读成已覆盖轴上。

无论哪种修法，都需要比现有 `hdiff`/`hint` 更强的正则性：现在只要求 ρ 方向逐点可微、`Γ_ρ` 区间可积，
不含 `Γ/ρ²` 在 ρ→0 的极限存在性，也不含 ζ 方向连续性。

### C2（证明审计员，minor）：`abs_Phi_le` 里的 `hΓ0` 冗余

**具体事实。** 证明审计员在副本上做对照实验：从 `abs_Phi_le` 删去 `hΓ0` 与 `simp` 中的 `hΓ0`、
并同步删去 `Phi_bound` 调用点的实参后，`lake env lean` 以 exit 0 通过；但从 `abs_Gamma_le` 删去
`hΓ0` 则报错，目标卡在 `⊢ |Γ ρ ζ t| = |Γ ρ ζ t - Γ 0 ζ t|`。所以 `hΓ0` 在 `abs_Phi_le` 内完全冗余
（ρ=0 分支由 `div_zero` 自动成立，ρ>0 分支用的是上游传入的 `h`，不再检查 `hΓ0`），
在 `abs_Gamma_le` 的积分步中不可省。整条 A34 仍真正依赖 `hΓ0`（经 `abs_Gamma_le`），
**这不是健全性错误**，只是子引理的假设略冗余。

**修法。** 从 `abs_Phi_le` 的签名删去 `hΓ0`，同步删去 `Phi_bound` 调用点对应的实参；
`abs_Gamma_le` 与 `Phi_bound` 保留 `hΓ0`。注意：这一冗余与 C1 同源——正因为 Lean 用 `x/0=0`
顶替了轴上值，ρ=0 分支才不需要 `hΓ0`。若按 C1 把 `Phi(0)` 改成极限值，轴上分支改由连续性处理，
`hΓ0` 在 `abs_Phi_le` 中仍然不需要，但结论会变强。

**附带文档问题。** `SPEC.md` §4 第 3 条把这个检验描述为"去掉 `hΓ0`，ρ=0 处仍通过而 ρ>0 处失败"。
按上述实验，失败只发生在 `abs_Gamma_le` 的积分步；`abs_Phi_le` 单独去掉 `hΓ0` 后两个分支都通过。
建议 SPEC 按"`abs_Phi_le` 内可删、`abs_Gamma_le` 内不可删"改写。

### C3（陈述强度审计员，minor）：`SPEC.md` §4.1 的锐度见证不满足 `hbound`

**具体错误。** SPEC §4.1 取 `Γ(ρ,ζ,t)=ρ²/(2(1+√-t))`、`C₁=1`，断言它满足假设且"等号恰好取到"。
实际上 `hbound` 要求 `|∂_ρΓ| ≤ C₁ρ/R`，而 `∂_ρΓ = ρ/(1+√-t)`，`ρ/R ≤ ρ/(1+√-t)` 且在
`(ρ,ζ)≠(0,0)` 时严格更小。取 `ρ=1, ζ=0, t=0`：左边 `∂_ρΓ=1`，右边 `ρ/R=1/2`，假设失败。
SPEC 把 `R` 的方向用反了：`R` 更大使 `ρ/R` 更小，假设比结论的被积函数更严。
审计员在 `Scratch/Audit-strength.lean` 用 Lean 验证了
`spec_witness_violates_hbound`（编译通过）。

**正确的锐度陈述。** 取极值族 `Γ(ρ,ζ,t)=∫₀^ρ r/R(r,ζ,t) dr`，则 `∂_ρΓ=ρ/R`，`hbound` 取等
（`GammaExt_deriv` 已验证）。其比值 `|Φ| / (C₁/(2(1+√-t)))` 在 `ζ=0` 时随 `ρ→0` 升向 1
（`ρ=0.1/0.01/0.001` 对应 `0.938/0.993/0.999`），恒严格 `<1`。所以 `1/2` 作为**上确界**是锐的，
但任何 `ρ>0` 都取不到等号。

**修法。** 把 SPEC §4.1 的见证换成 `Γ=∫₀^ρ r/R dr`，把"假设成立而等号恰好取到"改为
"上确界锐、不取到"；SPEC §4 第 1 条的"任何把它改小的形式化都会在这一族上失败"也应按此改成
"在这一族上比值趋于 1、故常数不能再降"。该错误只影响 SPEC 的可伪性检验，不影响 A34 的陈述或证明。

## 4. 仍然没有机器验证的部分

### 4.1 由 (H1)–(H3) 推出 `hbound`

论文的一行是：由 (eq:identities) `∂_ρΓ=ρω^ζ` 与 (H2) `|ω|≤C₁/R` 得 `|∂_ρΓ|≤C₁ρ/R`。
要形式化需要：从 ℝ³ 速度场 `u` 定义 `Γ=ρu^θ`、`ω=∇×u`；柱坐标下的旋度公式
`ω^ζ=(1/ρ)∂_ρ(ρu^θ)`；`|ω^ζ|≤|ω|`；以及 `|ω|≤C₁/R`。Mathlib 没有成形的 ℝ³ 旋度/向量微积分框架，
需先建 curl 与柱坐标链式法则（或局部坐标变换引理）。这是 A9 不能合成的原因，也是 `hbound` 只能是假设的原因。
附带一件簿记：`hbound` 量化到全部 `t∈ℝ`，论文只到 `t≤0`；合成时需把 `t≤0` 的解在 `t>0` 面常值延拓，
或把 `hbound` 改成 `t≤0`，结论不变。

### 4.2 `sup` 范数层

`A35` 是逐点一致版。论文的 `‖Φ(t)‖∞→0` 还需：定义 `‖Φ(t)‖∞ := sSup {|Φ ρ ζ t| : 0≤ρ, ζ∈ℝ}`；
用 A34（取 `ε=1`）证 `BddAbove`；证一条 `Phi_sSup_le : (∀ρ≥0 ζ, |Φ|≤ε) → sSup{...}≤ε`（`Real.sSup_le`）；
再用 `Filter.Tendsto` 把 `Phi_bound_tendsto` 组合成 `‖Φ(t)‖∞→0`。约 15–30 行，无分析内容，当前未做。
`BddAbove` 的必要性正是 A34 提供统一界的原因。

### 4.3 轴上的光滑提升

需要从 (eq:axis) `Γ=ρ²g`、`g` 光滑，定义 `Φ(0,ζ,t):=g(0,ζ,t)=lim_{ρ→0}Γ/ρ²`；证明该极限存在、
等于 Lean 在 ρ>0 的 `Phi` 的极限；再用 ρ>0 的一致界与连续性取极限得轴上界。当前 Lean 的
`Phi(0)=0`，所以论文的轴上断言**没有**机器验证。所需正则性强于现有假设：`hdiff` 只要求 ρ 方向在
ρ≥0 逐点可微，`hint` 只要求 `Γ_ρ` 区间可积，都不含 `Γ/ρ²` 在 ρ→0 的极限或 ζ 方向连续性。
修法见 C1。

### 4.4 论文的 `Φ` 与 Lean 的 `Phi` 在 ρ>0 的等同

ρ>0 时两者都是 `Γ/ρ²`，等同是定义性的；但论文的 `g` 是从 `u` 的轴正则性构造出来的，
把 `g` 与 `Γ` 联系起来的正是论文的环境光滑性/轴正则，形式化里没有。严格说这是 4.1 的一部分，
独立列出以免被"旋度"一词掩盖：即使 4.1 的旋度链建好，还要证明 `u` 光滑 ⇒ `Γ=ρ²g` 且 `g` 光滑。

### 4.5 Feynman–Kac 单调性 `M(t)≤M(s)`

不在 `prop:bound` 的范围内，但它是 `thm:main2` 的引擎（陈述强度审计员指出）。需要鞅问题/可选停止
或抛物极值原理；Mathlib 没有这一层，主定理无法形式化。缺它不影响 A34/A35 自身，但决定了
A34/A35 不能单独推进到主定理。

### 4.6 论文"只用到 (H1) 与扩散非退化"的声明

`AUDIT.md` 的未决事项已记：Lean 的假设集合没有 (H3)、(H4)，与论文那句话一致；但没有验证"逆否"
（即没有证明其余假设确实可以去掉）。这不是 A34 的缺口，而是论文那句话本身未机检。

## 5. 结论

A34/A35 能算作 `prop:bound` 的**条件积分步**的机器证据（常数、`≤` 方向、量词、无 `sorry`、
公理清洁度全部核实），但在 `(H2) ⇒ |∂_ρΓ|≤C₁ρ/R` 的推导与轴上光滑提升两处补上之前，
不能算作 `prop:bound` 本身的机器证明——A9 保持 `PROVED-INFORMAL` 是诚实的。
